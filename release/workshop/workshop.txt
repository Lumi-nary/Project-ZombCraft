title=Project ZombCraft
description=[h1]Project ZombCraft[/h1]
description=Play Project Zomboid as Minecraft's Steve. Project ZombCraft connects Project Zomboid Build 42 with a real Minecraft: Java Edition running beside it. Project Zomboid stays the world and the zombies; Minecraft brings Steve, his movement, blocks, inventory, survival and HUD.
description=
description=[b]This is the Project Zomboid half.[/b] You also need the Minecraft half, Project-ZombCraft for Fabric, from Modrinth (link below).
description=[b]Two Minecraft versions, one Project Zomboid mod:[/b]
description=[list]
description=[*][b]Minecraft 26.3[/b]: vanilla Minecraft. The main version, the full game.
description=[*][b]Minecraft 1.20.1[/b]: supports other Fabric mods, but buggy. Tested with Create (Fabric) and Viltrumite.
description=[/list]
description=[b]Single player only for now.[/b] Multiplayer is in development.
description=
description=[h2]You need[/h2]
description=[list]
description=[*]Project Zomboid Build 42 (42.21 or later) on Windows
description=[*]ZombieBuddy and Project Viewpoint (required items, see the right of this page). ZombieBuddy needs a one-time setup: follow its page.
description=[*]Minecraft: Java Edition in Prism Launcher, either:
description=[list]
description=[*][b]26.3[/b] with Fabric Loader 0.19.5, Fabric API, GeckoLib 5.5.7, Project-ZombCraft for Fabric @VERSION@ (the +mc26.3 file) and Java 25
description=[*][b]1.20.1[/b] with Fabric Loader 0.16 or later, Fabric API for 1.20.1, GeckoLib 4.8.4 for 1.20.1, Project-ZombCraft for Fabric @VERSION@ (the +mc1.20.1 file), any other Fabric 1.20.1 mods you want, and Java 17
description=[/list]
description=[/list]
description=
description=[h2]How to play[/h2]
description=[olist]
description=[*]Start Project Zomboid. Its main menu lists your Minecraft instances that have the mod: press Play and it starts yours (Prism Launcher, MultiMC, PolyMC; the last one starts by itself next time). With other launchers, start it yourself and Project Zomboid waits.
description=[*]While Minecraft loads, Project Zomboid shows its loading screen. Minecraft runs minimised; leave it running.
description=[*]Start a new game and choose Steve (Minecraft's character, no character creation, Minecraft's starter kit) or a Zomboid survivor (Project Zomboid's character in first person, never Steve). To change, start a new character.
description=[*]You start in first person. As Steve, Minecraft's HUD appears once Minecraft has opened the save's world.
description=[/olist]
description=The first time, ZombieBuddy asks you to approve Project-ZombCraft's Java code: approve it.
description=Each Project Zomboid save has its own Minecraft world, so Steve's inventory and your blocks stay with that save. Pausing Project Zomboid pauses Minecraft too.
description=
