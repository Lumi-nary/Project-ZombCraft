# Shared project continuity

Read `HANDOFF.md` first whenever taking over this workspace. It is the single working engineering plan, validation ledger and progress journal shared by Codex and Claude.

Follow the current user request and the handoff's owner decisions. Before game input, tests, installs or restarts, verify current processes/manual-play intent; a historical paused state is not current authorization. Documentation work does not require running gameplay tests.

Update `HANDOFF.md` after meaningful changes/builds/tests and before ending a session or reaching a usage limit. Keep its resume point current and append dated evidence, exact unfinished work and the next action. Update incrementally so an abrupt cutoff still leaves usable state. Distinguish implemented/built/installed/verified/failed/unverified/inconclusive.

Keep generated logs and test artifacts as evidence. README.md is the player's guide. Old plan/log Markdown files are redirects; do not create or update a competing progress file. Preserve private references, the owner's save/items/blocks, and the recorded backup/install safeguards.
